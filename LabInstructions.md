# Lab: Microsoft Purview Integration with Microsoft Defender XDR

## Exercise 1 – Investigate insider risk alerts and incidents in Microsoft Defender XDR

You are Joni Sherman, the Insider Risk Management Investigator for Corra Enterprises. Your role involves ensuring regulatory compliance and protecting sensitive information within the organization. Recently, Corra Enterprises has noticed unusual exfiltration activities via email that could potentially expose sensitive data to unauthorized recipients. To get the full view of activities conducted by this user detected across several Microsoft Security solutions from a single pane of glass, you want to share insider risk alerts with Microsoft Defender XDR.

### Tasks
1. Share insider risk alerts with Microsoft Defender XDR
2. Investigate insider risk alerts in Microsoft Defender XDR
3. Investigate incidents in Microsoft Defender XDR
4. Run KQL queries to hunt for threats in Advanced Hunting
5. Pull insider risk alert data through Microsoft Graph API

#### Task 1 – Learn how to share insider risk alerts with Microsoft Defender XDR

_In this task, you’ll discover how you can share insider risk alerts and other data with Microsoft Defender XDR._
1. Click on the settings icon on the top navigation bar
2. Click on “Insider Risk Management”
3. Under “Insider Risk Management settings”, go to “Data sharing”
4. The toggle for “Share user risk details with other security solutions” controls the flow of insider risk alerts and related data to Microsoft Defender XDR
5. Since this toggle was already on, insider risk alerts have already been flowing into Microsoft Defender XDR.

#### Task 2 – Investigate insider risk alerts in Microsoft Defender XDR

_In this task, you’ll investigate an insider risk alert in Microsoft Defender XDR._

1. Go to the Microsoft Defender XDR portal at security.microsoft.com
2. On the left pane, expand “Incidents & alerts” then click on “Alerts”. This will open the alerts queue.
3. Change the Alert time range filter to 30 days to see more alerts.
4. Click on any Alert that begins with “Purview IRM”. This indicates that the alert was generated by the Microsoft Purview Insider Risk Management solution.
5. Scrolling down, you will see the Insights on the left pane and the Activities under each insight.
6. Click on any Activity. This should open a panel on the side where you can conduct a deeper investigation into this particular user activity.
   
<brr> This is how you can view and investigate insider risk alerts in Microsoft Defender XDR. To get a detailed view of this insider risk alert, you can visit the corresponding alert page in the Insider Risk Management solution by clicking on “View alert in Purview” in the “What happened” section.

#### Task 3 – Investigate incidents in Microsoft Defender XDR

_In this task, you’ll learn more about investigating incidents in Microsoft Defender XDR._

1. On the left nav bar, click on “Incidents” under “Incidents & alerts”. This will open the incidents queue.
2. Change the Incident time range filter to 30 days to see more incidents.
3. Expand any Incident by clicking on the arrow left of the incident title. This will show a preview of all the alerts correlated within the incident.
4. Now click into the incident.
5. Here, you can see relevant alerts correlated within this incident.
6. You can read more about the incident on the right pane under “Incident details”.

<br> This is how you can investigate incidents with more than one alert logically correlated.

#### Task 5 – Pull insider risk alert data through Microsoft Graph API

_In this task, you’ll learn how to use Microsoft Graph to pull Insider Risk Management Alerts programmatically. We will use Microsoft Graph Explorer, which is an easy‑to‑use interface to make API calls._
1. Open a new tab in the browser and go to [https://developer.microsoft.com/en‑us/graph/graph‑explorer]
2. Click on the profile button near the top‑right corner to log‑in to Graph Explorer. This could be near the “Run query” button.
3. When a pop‑up window opens, sign in using the account displayed.
4. Run the following query in the query bar:
  <br> `https://graph.microsoft.com/v1.0/security/alerts_v2/irda294e0a‑2f7a‑428b‑a226‑28aadfa66cfd`
5. Analyze the results of this query in the “Response preview” tab
6. Next, we will run an Advanced Hunting query programmatically. Click on the dropdown next to “GET” and choose “POST” from the dropdown. In the query bar, put the following query:
  <br> `https://graph.microsoft.com/v1.0/security/runHuntingQuery`
